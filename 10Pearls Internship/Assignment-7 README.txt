Assignment 7 – Playwright Automation (Daraz.pk)

## 📌 Project Overview
This project automates functional testing of Daraz.pk using Playwright with Page Object Model (POM). The automation validates search, filters, product listing, product details, and free shipping availability.

---

Features Implemented

 1. Website Navigation
- Opened Daraz.pk successfully

 2. Product Search
- Automated search for "apple"

 3. Brand Filter
- Applied brand filter using checkbox selection

 4. Price Filter
- Applied price range filter (50000 – 500000)

 5. Product Validation
- Counted products in search results
- Asserted product count > 0

 6. Product Details
- Opened first product from results

 7. Free Shipping Validation
- Verified presence of "Free Shipping" text
